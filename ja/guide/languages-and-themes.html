      #言語・リンター・テーマ

      #言語

      言語パッケージをインストールし、その LanguageSupport オブジェクトを lang に渡します。

      <script setup lang="ts">
import { markdown } from '@codemirror/lang-markdown';
import CodeMirror from 'vue-codemirror6';

const lang = markdown();
</script>

<template>
  <code-mirror basic wrap :lang="lang" />
</template>

      公式の言語パッケージには次のものがあります。

      @codemirror/lang-angular、lang-cpp、lang-css、lang-html、lang-java、lang-javascript、lang-json、lang-lezer、lang-markdown、lang-php、lang-python、lang-rust、lang-sql、lang-vue、lang-wast、lang-xml

      コミュニティ製のパッケージも多数あります。CodeMirror の言語一覧 と README を参照してください。

      #リンター

      linter に LintSource を渡します。gutter を付けると、問題のある行にマーカーが表示されます。

      <script setup lang="ts">
import { json, jsonParseLinter } from '@codemirror/lang-json';
import { ref } from 'vue';
import CodeMirror from 'vue-codemirror6';

const value = ref('{ "key": "value", }');
</script>

<template>
  <code-mirror v-model="value" basic gutter :lang="json()" :linter="jsonParseLinter()" />
</template>

      JavaScript の場合、@codemirror/lang-javascript の esLint() と eslint-linter-browserify を組み合わせて使えます。

      import { esLint } from '@codemirror/lang-javascript';
import eslint from 'eslint-linter-browserify';

const linter = esLint(new eslint.Linter(), {
  languageOptions: {
    parserOptions: { ecmaVersion: 2022, sourceType: 'module' }
  },
  rules: { semi: ['error', 'never'] }
});
      Prop説明
      linterリンターのソース
      linter-configdelay などの リンターの設定
      force-lintingエディタがアイドル状態になるのを待たずに、すぐにリンターを実行します。
      gutterリンターのガターを表示します。linter を指定していない場合は効果がありません。
      gutter-configガターの設定

      診断結果の件数は インスタンス の diagnosticCount で取得でき、lint() で任意のタイミングでリンターを実行できます。

      Tip

      エディタ内で Ctrl+Shift+M(macOS では Cmd+Shift+M)を押すとリンターのパネルが開き、F8 で次の問題に移動できます。

      #テーマとダークモード

      • dark は、エディタの背景が暗いことを CodeMirror に伝えます。選択範囲やパネルなどの組み込み UI が暗い配色になります。
      • theme には EditorView.theme に渡すスタイル定義のオブジェクトを指定します。
      <script setup lang="ts">
import CodeMirror from 'vue-codemirror6';

const theme = {
  '&': { fontSize: '14px' },
  '.cm-content': { fontFamily: 'Menlo, monospace' },
  '.cm-gutters': { backgroundColor: 'transparent', border: 'none' }
};
</script>

<template>
  <code-mirror basic :dark="isDark" :theme="theme" />
</template>

      配布されているテーマの多くは拡張機能の形式なので、extensions で追加します。

      <script setup lang="ts">
import { oneDark } from '@codemirror/theme-one-dark';
import CodeMirror from 'vue-codemirror6';
</script>

<template>
  <code-mirror basic dark :extensions="[oneDark]" />
</template>

      例:@codemirror/theme-one-dark、@uiw/codemirror-themes、codemirror6-bootstrap-theme

      #その他の拡張機能

      CodeMirror の Extension は何でも extensions で渡せます。ほかの props から生成される拡張機能と組み合わせて適用されます。

      <script setup lang="ts">
import { EditorView } from '@codemirror/view';
import CodeMirror from 'vue-codemirror6';

const extensions = [EditorView.contentAttributes.of({ spellcheck: 'true' })];
</script>

<template>
  <code-mirror basic :extensions="extensions" />
</template>
      Info

      lang と linter も extensions で指定できます。これらが独立した props になっているのは、型付けと以前のバージョンとの互換性のためです。

      props が変わるとコンポーネントはエディタを自動的に再設定します。コンポーネントが検知できない変更をした場合は、インスタンスの forceReconfigure() を呼び出してください。
